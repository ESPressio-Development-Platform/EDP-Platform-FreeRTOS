# EDP-Platform-FreeRTOS Developer Wiki

EDP-Platform-FreeRTOS provides concrete EDP-Platform synchronization and execution-context providers implemented with the FreeRTOS API.

This Wiki is maintained beside the code on `main`. Source code and repository `docs/` remain the normative implementation and durable contract sources; the Wiki is the internal developer navigation and explanation layer.

## Public entry point

```cpp
#include <ESPressio_Platform_FreeRTOS.hpp>
```

## Dependencies

Mandatory: EDP-Platform.
